# Sankar Portfolio Website

## What is included
- `index.html` — all website content
- `style.css` — design, layout and responsive styling
- `script.js` — small mobile-menu interaction
- `assets/videos/` — the four portfolio project videos

## How to customize
1. Open `index.html` in VS Code (or another code editor).
2. Search for `Sankar`, `your@email.com`, `Instagram`, etc. and replace them.
3. The four project videos are included in `assets/videos/` and linked in `index.html`.
4. Change the project titles and descriptions.
5. The showreel section remains a placeholder; replace it with a separate showreel if desired.
6. Open `index.html` in a browser to preview.

## Easy hosting
You can upload this folder to Netlify or Vercel, or push it to GitHub and enable GitHub Pages.
